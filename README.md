# 📚 MyApp Frontend Assignments

A collection of **HTML, CSS, and JavaScript assignment pages** built as part of front‑end development training.  
This project demonstrates reusable layouts, modular assignment pages, and a clean login flow.

## 📂 Project Structure

├── assignments/         → Assignment pages

## 🚀 Features

- **Reusable Layout**  
  Sidebar + topbar stay fixed across all pages, with dynamic content loading via iframe.

- **Dashboard Hub**  
  Cards linking to all assignments (HTML, CSS, JS).

- **Assignments**  
  Each page demonstrates specific concepts:  
  - HTML Basics — structure, text formatting, lists, media, pseudo elements.  
  - HTML Semantics — semantic tags, forms, tables, articles.  
  - CSS Basics — backgrounds, borders, sizing, typography.  
  - CSS Compatibility — table layouts, list styles, grids, hero image, media queries.  
  - JavaScript Basics — arrays, loops, objects, hoisting.  
  - JavaScript Access & Properties — `this`, call/apply, counters, getters/setters, prototypes.  
  - JavaScript Events — listeners, validation, cookies, JSON.  

- **Login Page**  
  Clean, light UI with email/password validation, “Remember me”, and Google sign‑in button.

---

## 🛠️ Technologies Used

- HTML5 — semantic structure and accessibility  
- CSS3 — responsive layouts, grid/flexbox, animations  
- JavaScript (ES6) — DOM manipulation, events, validation  
- SVG — icons and logos  
- Responsive Design — media queries for mobile support

## 📖 How to Run

1. Clone the repository:  
   `git clone https://github.com/yourusername/myapp-frontend.git`  

2. Open `layout.html` in your browser.  
   - Sidebar and topbar will load automatically.  
   - Clicking links loads assignment pages inside the content area.
