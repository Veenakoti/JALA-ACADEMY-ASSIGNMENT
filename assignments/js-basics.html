JavaScript Basics Assignment

1. Comments

JavaScript supports single-line (//) and multi-line (/* ... */) comments.

// This is a single-line comment

/*
  This is a multi-line comment
  explaining multiple lines of code
*/

2. Fruits Array Sort (Descending)

Original array: ["Apple","Banana","Mango","Orange","Grapes"]

let fruits = ["Apple","Banana","Mango","Orange","Grapes"];
let sorted = fruits.slice().sort().reverse();

3. For/In Loop

The for...in loop iterates over object properties.

let car = { brand:"Tesla", model:"Model 3", year:2026 };
for (let key in car) {
  console.log(key + ": " + car[key]);
}

4. Person Object

Objects can be accessed using dot notation (person.firstname) or bracket notation (person["firstname"]).

let person = { firstname:"Kunal", lastname:"Sharma" };
console.log(person.firstname + " " + person.lastname); // dot
console.log(person["firstname"] + " " + person["lastname"]); // bracket

5. Variable Hoisting

Declarations are hoisted to the top, but initializations are not.

function hoistDemo() {
  console.log(x); // undefined
  var x = 10;
  console.log(x); // 10
}

6. Strict Mode Example

Strict mode prevents using undeclared variables.

"use strict";
undeclaredVar = 5; // Error: not declared
