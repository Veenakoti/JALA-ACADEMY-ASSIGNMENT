Quick Notes & Checklist

Importance of DOCTYPE

Include <!DOCTYPE html> at the top of HTML documents to ensure standards mode rendering in browsers.

Link external stylesheet

Use the syntax: <link rel="stylesheet" href="styles.css"> inside the document <head>.

Files & performance

  • Place background image at images/bg-hero.jpg (desktop) and images/bg-hero-small.jpg (mobile) or update the URL in CSS.
  • Optimize images (resize and compress) to reduce load time.

Submission checklist

  • CSS comments included
  • Background color + fixed image + size demonstrated
  • Four different border styles on each side
  • Height/width examples in px and percent/viewport
  • Font styles, sizes, families, colors, alignment
